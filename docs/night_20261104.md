## Biggest fixes
1. **The GPU problem you saw was real.** On a laptop without a MUX switch, the NVIDIA card can be asleep or resetting when a model
   server starts. The server then silently ran everything on the CPU for hours, which is why the card never spiked. Now each server
   is checked after it starts. If the card was not used, the server is started again on the card; if that still fails, the machine
   map says plainly that it is running on the CPU.
2. **The planner model can stay loaded next to the worker.** The 35B MoE ran at 14-16 tok/s with the worker loaded at the same time,
   and switching between them takes about 1 s instead of a 15-20 s model swap. This only takes effect if you choose the MoE as the
   heavy model.
