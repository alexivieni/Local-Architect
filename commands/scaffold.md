Start a new project: {args}

Create the smallest layout that runs: a package or entry point, one real feature from the description working, a test that passes, a
README with install, run and test commands, and a dependency file. Prefer the standard library. Run the test before you finish. Do not
add frameworks, configuration or folders the description does not need, and leave no placeholder or TODO stubs.
